## 1. TOKEN BUDGETS & RATE LIMITS

- **Storefront Customer Chat**: Maximum 50 messages per hour per customer session.
- **Admin Copilot Queries**: Maximum 200 queries per hour per administrator.
- **Bulk Marketing & Content Generation**: Maximum 50 SKUs processed per batch.
- **Cost Minimization**: All high-frequency operations (semantic search, recommendations, demand forecasting) run on zero-cost deterministic and statistical PHP algorithms without external API token costs.
